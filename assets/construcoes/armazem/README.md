# Armazém

Para cada modelo (`classico`, `acolhedor`, `rustico`) são necessários:

- uma textura base transparente, com telhado, portas, janelas e detalhes;
- uma máscara branca/transparente contendo apenas as paredes recoloríveis.

Também falta uma textura transparente para os materiais do local de obra.
As imagens são atribuídas em `resources/construcoes/armazem.tres`.
