# Assets modulares

Esta pasta recebe a arte que deve permanecer independente da ilustração de
fundo. Os ficheiros atuais em `resources/` continuam válidos e não foram
movidos para evitar quebrar referências existentes.

- `cenarios/`: fundos sem terrenos, culturas ou construções incorporados.
- `construcoes/`: texturas por nível de cada construção.
- `terrenos/`: bases e estados visuais dos terrenos.
- `culturas/`: sprites das culturas.
